# 桌宠来源与许可说明

## 角色素材

公开版本的桌宠使用仓库内的本站原创 `assets/reimu.svg`，不包含本地留存的第三方立绘或原始素材包。

## 交互设计参考

桌宠的延迟加载、台词、工具栏、拖动、关闭和重新唤起行为参考：

- [stevenjoezhang/live2d-widget](https://github.com/stevenjoezhang/live2d-widget)
- 上游代码许可证：[GNU General Public License v3.0](https://github.com/stevenjoezhang/live2d-widget/blob/master/LICENSE)

本项目没有复制或打包该仓库的运行时代码，也没有包含 Cubism Core；当前实现是针对普通 SVG 独立编写的静态降级组件，因此不会把非 Live2D 素材伪装成 Cubism 模型。

## 本项目许可状态

桌宠交互代码适用仓库根目录的 MIT License；原创角色图形与文章内容适用 README 中声明的 CC BY-NC-SA 4.0。
