# 桌宠来源与许可说明

## 角色素材

- 绘制：meroza
- 原始配布：[立ち絵素材（博麗霊夢・フランドール・スカーレット）（BOOTH）](https://booth.pm/ja/items/5655726)
- 本站使用：`models/reimu-static/reimu.png` 的睁眼差分，仅作为网页静态桌宠显示。
- 原配布规约：遵守东方 Project 二次创作指南；允许明度、色调、切取、缩放等加工；禁止商业使用（官方允许范围内的广告收入除外）、自作声明及再配布，包括加工后的素材。

该 PNG 不适用本项目的代码或原创 SVG 许可。请勿从本站单独提取、转载、商用、再上传或打包分发；如需使用，请前往作者原始配布页获取并遵守其最新规约。

## 交互设计参考

桌宠的延迟加载、台词、工具栏、拖动、关闭和重新唤起行为参考：

- [stevenjoezhang/live2d-widget](https://github.com/stevenjoezhang/live2d-widget)
- 上游代码许可证：[GNU General Public License v3.0](https://github.com/stevenjoezhang/live2d-widget/blob/master/LICENSE)

本项目没有复制或打包该仓库的运行时代码，也没有包含 Cubism Core；当前实现是针对普通 PNG 独立编写的静态组件，因此不会把非 Live2D 素材伪装成 Cubism 模型。
