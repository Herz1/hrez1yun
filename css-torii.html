用纯 CSS 画一座朱红鸟居

2026-06-17技术898 字约 3 分钟

鸟居的结构很适合用 CSS 拆解：两根柱、两道横梁和中央的小额束，都是规则几何形。真正决定它是否有“站在参道入口”感觉的，不是堆多少细节，而是比例、层次与一点点向上的弧度。

绘图规则：一个元素负责主体，伪元素负责左右对称的部件；能用变量表达的尺寸，就不要在十个地方重复数字。

先搭出五根木料

建立一个固定宽高的容器，把两根柱放在左右约四分之一处。上方第一道横梁略宽于容器，第二道横梁短一些，二者之间留出呼吸感。中央额束只需一块深色小矩形，既能形成视觉中心，也能遮住横梁交接处。

.torii {
  --red: #c73e3a;
  --wood: #8d2828;
  position: relative;
  width: 18rem;
  height: 14rem;
}
.pillar { position: absolute; width: 1.4rem; height: 11rem; }

左右部件可以让一个元素通过 box-shadow 复制，也可以分别创建两个子元素。前者代码短，后者更便于做透视与响应式调整；用于 Hero 主视觉时，我更偏向后者。

用伪元素抬起屋梁

完全水平的横梁容易像门框。让顶部横梁中央略低、两端微翘，轮廓就会立刻接近鸟居。CSS 中可以用一个宽矩形作主体，再用左右伪元素旋转两三度；接缝藏在同色阴影下，不需要复杂的裁剪路径。

柱子也不必绝对平行。使用很轻的 skewX 或让底部略宽，可以暗示重量。变形幅度必须克制：缩略图中的一两度已经足够，过度透视会把庄重感变成卡通门牌。

朱红不是一种颜色

正面使用明亮朱红，侧边和接缝使用偏暗的木红，再沿上缘放一条半透明高光。仅靠三档颜色，就能让扁平矩形具有体积。阴影不要纯黑，可选带红或紫的透明色，使它与页面的和纸色、永夜色都能融合。

background: linear-gradient(90deg,
  var(--wood) 0 8%,
  var(--red) 8% 88%,
  #e35a4f 88% 100%);
box-shadow: 0 12px 24px rgba(75, 31, 35, .2);

把尺寸交给容器

将内部尺寸统一写成 em，容器只需改变 font-size 就能整体缩放。窄屏降低尺寸，装饰性阴影也随之减弱；在减少动态模式下关闭浮游动画。最后给整个图形设置 aria-hidden="true"，因为它是氛围装饰，不应让读屏软件逐个朗读无意义的木料。

纯 CSS 图形最适合结构简单、需要随主题换色的装饰。若细节开始依赖大量裁剪和定位，SVG 会更清楚。工具没有胜负，保持源码可读、页面稳定才是选择标准。
