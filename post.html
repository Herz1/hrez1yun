从零打造东方 Project 风格博客：弹幕引擎与和风设计

2026-07-24 教程 1430 字 约 5 分钟

把「幻想乡」搬进浏览器需要回答两个问题：哪些元素一眼就是东方，以及如何在没有任何图片素材的前提下把它们画出来。本文记录本站的完整实现思路——从设计语言、弹幕引擎到 GitHub Pages 部署，全程零构建、零依赖。

符卡宣言：「境符『本地与线上的完全一致』」——双击 HTML 直接打开，与部署到域名后的表现分毫不差。

和风设计语言：朱、金、藏青

配色取自神社意象：鸟居的朱红（#c73e3a）作为主色，饰件的金（#d9a441）作为点缀，藏青与和纸色负责底与面；夜间模式则切到「永夜」——深紫夜空加一轮满月。全部颜色收敛为 CSS 变量，昼夜切换只是替换一层 data-theme：

:root        { --paper:#faf4e9; --sky-a:#a8d2ea; }
html[data-theme="night"]
             { --paper:#14122b; --sky-a:#0d0b20; }

字体分三层：书法体负责站名与符卡名，宋体负责标题，黑体负责正文。传统纹样则用矢量手绘——页脚的青海波是一段 40×20 的 SVG data URI 平铺，Hero 底部的霞云用「纸色圆角矩形」切出，换肤时跟随背景色自动过渡，无需两套素材。首页浮空的灵梦立绘采用授权透明 PNG 分层叠放，光环、阴阳玉、御札与浮游效果仍由本站 CSS 动画完成。

弹幕引擎：一个 Canvas 就够了

东方的灵魂是弹幕。本站的 DanmakuFX 引擎只有一百多行：维护一个子弹数组，每帧更新位置并绘制「彩色外圈 + 白色内核」的经典弹形。环形弹幕的生成不过是一段极坐标：

for (let i = 0; i < n; i++) {
  const a = (i / n) * Math.PI * 2;   // 均分一圈
  spawn({ x: cx, y: cy,
          vx: Math.cos(a) * speed,
          vy: Math.sin(a) * speed });
}

隐藏符卡的全屏螺旋则借用了黄金角 2.39996 rad：每次发射角度递增黄金角，弹幕自然长成一朵不重叠的花。工程细节上做了三件事：子弹数量封顶（移动端减半）、标签页隐藏时暂停渲染、检测到系统「减少动态」偏好时整个引擎不启动。

符卡化的小组件

各家优秀博客的亮点，这里全部换上了幻想乡皮肤：

  • 阅读进度：不止一条顶栏，还有一枚「BOSS 符卡」药丸——随滚动显示当前小节的符卡名与 ★ 进度（你现在抬头就能看到）。
  • 标签：做成御札（护符）造型，左侧一道朱印，悬停时微微翘起。
  • 代码块：右上角悬浮「复制」按钮，成功后 Toast 提示「已复制符文 ✓」。
  • 返回顶部：圆环用 conic-gradient 画出滚动百分比，悬停时数字变箭头。
  • 快捷键：S 唤起本地搜索，D 切换昼夜，文章页 ←/→ 直接跳上下篇。
  • 点击擦弹：点击空白处会炸开一小圈弹幕并飘出 Graze +N，页脚有累计。
还有一张真正的隐藏符卡：在任意页面输入 ↑↑↓↓←→←→BA——祝你擦弹愉快。

部署：GitHub Pages 与「本地=线上」

让 file:// 双击、本地服务器、用户名.github.io/仓库名 三种打开方式表现完全一致，靠的是四条纪律：

  1. 全相对路径：所有引用写成 ./css/style.css 这种形式。GitHub 项目页部署在子路径下，绝对路径 /css/… 会直接 404。
  2. 零构建：没有 npm、没有打包器，仓库里的文件就是最终产物。
  3. 不用 fetch 拉数据：文章索引写在 js/posts-data.js 里用 <script> 引入。若用 fetch('posts.json')，file:// 协议会被浏览器跨域策略拦下，本地直接双击就会白屏。
  4. 加一个 .nojekyll：告诉 GitHub 跳过 Jekyll 处理，原样托管。

部署三步：仓库推上去 → Settings → Pages → Source 选 main 分支根目录。约一分钟后你的神社就在线上开张了。唯一联网依赖是 Google Fonts，断网时会优雅回退到系统字体。

尾声：二次创作的礼仪

本站没有使用官方图片素材。首页灵梦立绘、管理人头像和静态桌宠分别依素材作者的配布规约使用，鸟居、阴阳玉、弹幕、御札等 SVG 元素为本站原创二次创作；文字中对作品与曲目的提及属于介绍与评论。作为爱好者，请记得：东方 Project 的同人创作受惠于官方公开的二次创作指引，非营利、注明二创身份、不冒充官方是底线。愿幻想乡长存，也愿你的博客常新。
